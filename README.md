# もりの おいかけっこ

お猿さんとタヌキさんが、仲良く鬼ごっこするブラウザーゲームです。
プレイヤーはタヌキさん。逃げるお猿さんにタッチするとタヌキさんの勝ち！
時間制限もゲームオーバーもありません。

## あそびかた

- **矢印キー / WASD / 画面の方向ボタン**：タヌキさんを移動
- **スペース / ダッシュボタン**：短いダッシュ（3秒で回復）
- **Esc / ひとやすみボタン**：一時停止と再開
- 「のんびり」「ふつう」「げんきいっぱい」の3段階
- 効果音は初期状態でオフ。「音：オフ」ボタンで切り替え
- スマートフォンのタッチ操作に対応

## ローカルで遊ぶ

`index.html` をブラウザーで開いてください。インストール、ビルド、外部素材の読み込みは不要です。
開発用サーバーを使う場合は `node server.cjs` を実行し、`http://127.0.0.1:4173` を開きます。

## GitHub Pages で公開

このフォルダーのファイルを GitHub の公開リポジトリに登録し、リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch**、**main / (root)** を選んで保存します。
Pages のデプロイ完了後、表示される URL から遊べます。

## 実装と確認

HTML / CSS / JavaScript と Canvas 2D で制作。イラスト・効果音はコードで生成し、外部ライブラリー、通信、トラッキングは使用していません。

- `engine.js`：移動、障害物、逃走 AI、ダッシュ、勝利判定
- `game.js`：描画、入力、効果音、画面遷移
- `node --test engine.test.cjs`：ゲームロジックのテスト

画像・音声ファイルのダウンロードは不要です。
